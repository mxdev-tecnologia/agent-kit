# Language

- Write every document that agents read in English: specs, skills, agent definitions, workflows, rules, plans, reports and code comments.
- Keep terms stable. Use the same word for the same concept across documents, and prefer plain, short sentences.
- Do not decide the language of commit messages, pull request text, changelogs or any text shown to end users. The project sets that language (see its instructions file). When the project does not say, ask once and record the answer.
- Identifiers, file names, envelope kinds and schema keys stay in English regardless of the project language.
